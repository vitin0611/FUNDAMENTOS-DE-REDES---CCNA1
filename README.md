# FUNDAMENTOS-DE-REDES---CCNA1
Repositorio académico orientado al estudio e implementación de los conceptos esenciales de Redes de Computadoras. Incluye prácticas de laboratorio, configuraciones de dispositivos Cisco, simulaciones en Packet Tracer, direccionamiento IPv4 e IPv6, subneteo, protocolos de comunicación, modelos OSI y TCP/IP, seguridad básica de redes y documentación.
