## 📚 Contenido del Repositorio

Este repositorio incluye:

- Configuraciones básicas de dispositivos Cisco
- Prácticas de laboratorio en Packet Tracer
- Direccionamiento IPv4 e IPv6
- Subneteo y cálculo de redes
- Modelos OSI y TCP/IP
- Protocolos de red
- Configuración de routers y switches
- Seguridad básica de redes
- Documentación técnica y reportes académicos

Centralizar todas las prácticas, proyectos, configuraciones y recursos desarrollados durante el curso, sirviendo como apoyo académico y referencia para futuras implementaciones de redes.

- IPv4 / IPv6
- Switching & Routing
- SSH y configuración remota
- Redes LAN
